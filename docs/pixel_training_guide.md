# 原图像素交互训练指南

## 它解决什么问题

v0.3 的训练器只能对已经被传统检测器找到的候选框做“目标/伪影”二次分类。像素交互训练允许研究人员直接在原图 ROI 上画样本，使程序学习哪些源像素更像目标图像类，再把概率图转换成候选点。它仍是用户监督训练，不会在没有人工标签时“自主理解”物理位错。

## 创建项目

1. 打开本机工作台的“图像交互训练”，或 GitHub Pages 的 `train.html`。
2. 选择未经过 JPEG 有损处理的原始图；优先使用原始 TIFF。
3. `wafer_id` 必须在同一物理晶圆的所有裁片中保持一致。
4. 用于训练的晶圆选择 `calibration`；只用于调研泛化的选择 `validation`；最终一次性评价的选择 `locked_test`。
5. 记录标注者 ID。项目保存原图 SHA-256、灰度归一化窗口、数据用途和操作历史。

训练项目 JSON 不嵌入原始图像。重新载入项目时必须重新选择同一文件，程序会核验 SHA-256；不匹配时拒绝恢复，避免标签错位。

## 画标签

- 红色“目标/前景”：只涂研究人员确信属于目标图像形貌的像素。
- 绿色“背景/伪影”：包括普通背景、纹理、划痕、线状结构、灰尘或其他确定负例。
- 黄色“忽略/不确定”：保留争议区域，但这些像素既不作为正类也不作为负类参加训练。

滚轮缩放，平移工具或按住空格拖动。画笔实际写入的是 ROI 原始像素索引；缩放、窗口大小和屏幕像素不会改变标签坐标。可以撤销、重做、清除单类以及临时隐藏标签。

## 训练与即时纠错

每类至少需要 20 个标注像素。实际研究中应覆盖多张图、多个晶圆区域、不同背景和对比度，而不是只在一个明显目标上画满像素。

训练后页面显示：

- 目标图像类概率图；
- 概率阈值与最小面积处理后的分割掩膜；
- 人工标签和模型预测边界叠加图；
- 像素级 precision、recall、F1、IoU；
- 目标级 precision、recall、F1、假阳性、假阴性和定位误差。

当前 ROI 指标仅用于找错。发现漏检时在漏检处补红色标签；发现误检时在误检纹理或伪影处补绿色标签，然后重新训练。不要为了让训练指标变好而把不确定样本强行标成背景。

## 模型做了什么

程序计算不含坐标的多尺度灰度特征：原始强度、Gaussian、DoG、局部均值和标准差、Sobel 梯度、Gaussian Laplacian、Hessian、结构一致性和暗目标响应。类别平衡采样后，以固定随机种子训练可移植随机森林。JSON 保存：

- schema 和软件版本；
- 特征配置与严格顺序；
- 树结构与训练参数；
- 类别映射和标签数量；
- 原图 SHA-256、wafer_id、split 与 ROI；
- probability threshold、minimum object area；
- validation/locked test 指标状态；
- 内容 SHA-256。

本机和浏览器都调用打包的同一 Python 特征与推理实现，不另写一套 JavaScript 分类器。

## 应用于完整分析

本机训练模型保存在 `training/pixel_classifier.json`。在“新建分析”勾选“像素级原图训练模型”；GitHub Pages 则上传模型 JSON。大图按重叠 tile 推理，halo 覆盖最大特征邻域，tile 核心区唯一归属，避免接缝重复。

像素模型只能提出前景连通域。最终目标仍受下列硬规则约束：

- 最终有效分析掩膜；
- edge exclusion 与实际有效边界距离；
- 最小/最大面积、长宽比、圆度、solidity、对比度等；
- 可选 v0.3 候选级分类器。

`defects_all.csv` 和局部 Excel 分开保存像素概率、像素阈值、像素模型哈希、规则判定、候选模型判定和最终判定。

## 怎样解释验证结果

- training/calibration：用于拟合和纠错，不是最终性能。
- validation：可以反复查看，但不应用于宣称锁定性能。
- locked test：不得用于选阈值、选特征或反复纠错。
- 没有真实专家标签：只能说明软件闭环在合成场景可运行，真实准确率未知。
- 没有 DIC/KOH 或其他独立物理证据：只能写“模型预测的点状图像目标”，不能写“已确认 TSD/TED/BPD”。

Rigaku 文献中的约 50×30 μm TSD 形貌来自特定材料、Cu Kα 和 (008) 条件，只能帮助设置研究假设或诊断可解析尺度，不能硬编码成所有设备的通用真值。

## 大图限制

本机训练 ROI 上限为 2048 px；GitHub Pages 为控制 WebAssembly 峰值内存，限制为 1024 px。原图预览只用于选区，训练和预测使用源分辨率 ROI。兼容 TIFF 使用有界区域读取；静态网页不满足格式、内存或随机访问安全条件时会明确停止，不会用缩略图替代科研训练。
