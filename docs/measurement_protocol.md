# SiC X 射线形貌点状目标测量协议

## 1. 输入图像

优先使用未压缩或可追溯的原始 TIFF；16 位和浮点输入以同一全局百分位窗口归一化为 float32 `[0,1]` 后进入科研检测，PNG 仅用于显示。整片晶圆图应尽量包含完整圆周；局部裁片必须另行给出像素标定和有效区域，不能据此虚构整片面积密度。

## 2. 100 mm 物理标定

按拟合晶圆直径 `D_px` 与实际 100 mm 计算 `mm_per_pixel = 100 / D_px`。同时保存拟合可信度、真实轮廓与是否裁剪。低可信度或严重裁剪而未人工指定几何时，程序必须拒绝输出密度。

## 3. 有效分析区域

`valid_analysis_mask = full_wafer_mask - edge_exclusion_mask - invalid_mask`。面积为有效像素数乘以 `(cm_per_pixel)^2`，而不是无条件使用理想 78.5398 cm²。平边、notch、边缘排除、遮挡、文字或用户声明的坏区均从面积中移除。

## 4. 点状目标判定

程序以背景校正后的暗响应生成候选，并提取面积、等效直径、长宽比、离心率、圆度、solidity、局部对比度及到最终有效边界的距离。可选分水岭只用于保守分离粘连点；长线和大暗区保留为候选但按规则拒绝。所有阈值必须用研究组的专家标注校准，不能把默认参数视为物理标准。

## 5. 人工复核

输出带编号叠加图、全部/接受/拒绝 CSV 与原始候选裁剪。审阅者可以修改 `accepted`，但原始自动结果和拒绝原因必须保留，便于复现和漏检检查。

原图像素交互训练是可选的前置候选生成方法。专家在源分辨率 ROI 上分别画目标前景、背景/伪影和 ignore；ignore 不参加拟合。程序提取不含绝对坐标的多尺度灰度、Gaussian/DoG、局部统计、梯度、Laplacian、Hessian、结构与暗响应特征，使用固定随机种子和类别平衡随机森林输出概率。概率连通域仍需通过最终有效掩膜、边缘与形态硬规则。模型在像素尺度上训练，因此只应跨经过验证的相容分辨率和成像条件应用；域变化需重新验证。

## 6. 密度

当前规则接受数为 `n`，有效面积为 `S`（cm²），报告 `rho = n / S`（cm^-2）。泊松计数标准不确定度为 `sqrt(n) / S`，Garwood 区间仅表示有限计数随机误差。

## 7. 真实验证

真实验证采用版本化专家标注 CSV。`confirmed_point` 是明确正类；`possible_point` 与 `uncertain` 不得作为负类。校准、验证和锁定测试按 `wafer_id` 分离，避免同一晶圆不同 patch 泄漏。报告图像规则相对标注的 TP/FP/FN、precision/recall/F1、按晶圆 bootstrap 分类偏差和分歧；这些结果不证明黑点一定对应物理位错。

论文式红框/黄圈图遵守额外门禁：红框是本程序自动 XRT 候选；黄色圈只来自已经配准且源 XRT、独立 DIC/KOH（或明示的专家参考）图像哈希均匹配的 `confirmed_point`。参考覆盖未声明完整时，不把未匹配自动候选作为假阳性，也不计算 precision/F1。参考坐标只用于对照和误差评估，不得回写自动 `accepted`、`n`、`S` 或 `rho`。

## 8. 不确定度

分别报告计数泊松区间、真实验证的分类偏差、局部参数敏感性、面积/标定不确定度（仅在有输入时）和空间异质性。默认不将这些来源强行合并为单一 ± 值。

## 9. 空间分布

径向环、角向 sector 和 center/middle/edge 区域的面积均从最终有效掩膜逐像素计算。每个 bin 报告有效面积、count、density 和泊松区间。默认径向使用近似 equal-area 的实际有效面积分箱；角度参考为图像正 x 轴。

## 10. 解释限制

外圈 count 增多不等于外圈 density 更高。角向差异没有统一 notch/flat 或晶向坐标时不能解释为晶体学方向。单片晶圆的局部富集是描述性结果；工艺或生长机制推断需要多片晶圆、统一实验条件和相关元数据。程序不能替代材料专家的物理判定。
