方法、验证与可重复性

面向研究复核的测量定义，而不是物理结论自动化

测量定义

n当前规则接受的点状目标数÷S最终有效像素掩膜面积=ρ点状目标密度 cm−2

S 不是无条件使用 78.5398 cm²，而是由真实晶圆轮廓、边缘排除区、notch / flat、遮挡和用户无效区共同决定。

处理流程

  1. 以全局分位数窗口将原始灰度映射为 float32。
  2. 在预览图检测晶圆并映射回原图标定 100 mm。
  3. 构建最终有效分析掩膜，按有效像素计算 S。
  4. 背景校正、多尺度暗目标增强与阈值产生候选。
  5. 可选保守分水岭处理粘连，形态与对比度规则筛选。
  6. 保存全部候选、拒绝原因、裁剪、叠加图与配置。

真实数据验证状态

当前未在真实 SiC 专家标注数据上完成性能验证

合成 clean / noisy / difficult 测试证明软件行为可重复，并不能证明真实图像 precision、recall 或物理位错识别准确率。

真实验证必须按 wafer_id 分离 calibration、validation 与 locked test，保留多标注者原始标签与分歧。
